# Operator Console

This directory will contain the Angular single-page application used by the
payment operations analyst.

Initialize the Angular workspace here with:

- Routing enabled
- SCSS styling
- Strict TypeScript
- No nested Git repository

Retain `AGENTS.md` during initialization.

The initial UI should contain only the alert queue, incident workspace,
investigation report, human decision controls, and audit timeline needed for
the first vertical slice.
