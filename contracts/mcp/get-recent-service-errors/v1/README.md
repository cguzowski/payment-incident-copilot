# getRecentServiceErrors v1

This directory is the immutable repository-owned wire contract for the
`getRecentServiceErrors` MCP tool. The metadata, schemas, and canonical
synthetic fixtures are consumed by both the provider and consumer test suites.

Backward-compatible clarifications may be documented without changing the
wire shape. A backward-incompatible input, output, annotation, or semantic
change requires a sibling `v2` contract; do not rewrite `v1`.
