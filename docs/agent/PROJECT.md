# Project definition

This local synthetic payment incident copilot gathers MCP evidence, retrieves
approved PDF knowledge, generates advisory Ollama reports, and records explicit
human review and an audit trail. It supports seven incident families for one
fictional tenant, SynTen Inc. It does not process money or execute recommendations.

The owner has ended feature development and requested a runtime-focused Git
repository. Retain only current application/build/startup inputs, required knowledge
and provenance, public contract pins, configuration examples and concise guidance.
Tests and past development/evaluation records are no longer maintained.
